# FreshTrack – Food Expiry and Waste Prevention

## Project Overview
FreshTrack is a Java-based application designed to track food expiry dates and help prevent food wastage.

## Objectives
- Track food items and their expiry dates.
- Identify food items nearing expiry.
- Send expiry alerts to users.
- Reduce food waste through proper food management.

- Exception Handling
- Multithreading
